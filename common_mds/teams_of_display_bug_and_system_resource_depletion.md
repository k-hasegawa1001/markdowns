# トラブルシューティング備忘録：Teamsの表示不具合とシステムリソース枯渇

## 1. 症状

- PC全体の動作が異常に重い。
- **Teamsの表示不具合:**
  - 過去の投稿履歴のみが表示されない（真っ白になる）。
  - リアルタイムでの新規投稿は表示される。
  - 「共有済み」に入っているフォルダやファイルなどは正常に閲覧可能。
  - 他のユーザー（友人など）の環境では正常に表示されているため、サーバー側の障害ではない。

## 2. 心当たり

- 前日にFlutterのテストコード実行とビルド（`$ flutter test ...`）を何度も繰り返し、高負荷な作業を長時間行っていた。
- その過程でAndroidエミュレータ（`qemu-system`）やビルドプロセスがゾンビプロセス化し、システムリソース（メモリやVRAM）を異常に消費していた。
- PCの冷却ファンが常時高速回転するほどの熱と負荷が発生していた。

## 3. 疑問に思ったこと

**「作業終了後にPCをシャットダウンしたにもかかわらず、なぜゾンビプロセスやシステムリソースの異常状態が解消されていなかったのか？」**

## 4. シャットダウンで解決しなかったOS・ハード的な仕組み

- **Windowsの「高速スタートアップ」機能の存在**
  Windows 10以降では「高速スタートアップ」が標準で有効になっている。この機能がオンの場合、スタートメニューからの「シャットダウン」は完全な電源オフではなく、OSのコア部分（カーネル）やデバイスドライバの現在の状態をディスク上の休止状態ファイル（`hiberfil.sys`）に保存する「ハイブリッドシャットダウン」として機能する。
- その結果、リソース枯渇によって異常をきたしていたグラフィックドライバやメモリ管理の状態が破棄されず、翌日の起動時にそのまま復元されてしまった。タスクマネージャーのパフォーマンスダッシュボード上で、CPUの稼働時間（アップタイム）が「13日」などと表示されていたのがその証拠である。

## 5. 根本原因

上記の要素が複合し、以下のプロセスで不具合が発生した。

1. **リソース枯渇によるレンダラープロセスへの影響:**
   前日の高負荷作業によってシステムリソース（メモリ、VRAM）が極度に枯渇。TeamsはWebView2（Chromiumベース）を使用して画面を描画しているが、リソース不足によりUI描画を担当するレンダラープロセスが正常に機能しなくなった。
2. **データベース（キャッシュ）の破損:**
   リソース枯渇による不安定な状態の中で、Teamsがバックグラウンドでチャット履歴などのデータをローカルキャッシュ（SQLite等）に保存しようとして失敗。ローカルデータベースのインデックスが破損した。
3. **異常状態の持ち越し:**
   PCを「シャットダウン」したことで、高速スタートアップの働きによりシステムの異常状態がそのまま翌日に持ち越された。
4. **症状の固定化:**
   「再起動」によってOSの異常状態はリセットされたが、Teamsのローカルキャッシュの破損はそのまま残ったため、「新しく受信したメッセージはメモリ上に直接描画されるため見えるが、ローカルDBから読み込む過去の履歴は表示されない」という局所的な不具合が生じた。

## 6. 解決手順

### 解決のメカニズム

ローカルに保存されているTeamsのキャッシュファイル（破損したデータベース）を完全に削除（初期化）する。これにより、次回Teams起動時にローカルデータが存在しないと認識され、クラウドサーバーから過去のチャット履歴データが再ダウンロード（再フェッチ）され、正常な状態に復元される。

### 【重要】アイコンの罠とバージョンの特定

タスクバー上のアイコンが「従来のTeams（Classic Teams）」に見える場合でも、アイコンのキャッシュバグなどにより、**実体は「新しいTeams（New Teams）」である可能性**がある。
誤った手順を防ぐため、まずはタスクマネージャーから実行ファイルのパスを確認する。

1. Teamsを起動した状態でタスクマネージャー（`Ctrl + Shift + Esc`）を開く。
2. プロセス一覧から「Microsoft Teams」を右クリックし、「ファイルの場所を開く」を選択。
3. 実行ファイル（`ms-teams.exe`）のパスを確認する。
   - **新しいTeams:** `C:\Program Files\WindowsApps\MSTeams_...` のようなパッケージ化されたパス。
   - **従来のTeams:** `%localappdata%\Microsoft\Teams` 等のユーザープロファイル直下のパス。

### キャッシュ削除の具体的な手順

#### パターンA：新しいTeams（New Teams / MSIXパッケージ版）の場合

WindowsApps内で管理されているため、手動でのフォルダ削除ではなく、OSのシステム機能からリセットを行う。

1. システムトレイ（画面右下）のTeamsアイコンを右クリックし、「終了」を選択してTeamsを完全に閉じる。
2. `Windows + I` キーを押してWindowsの「設定」を開く。
3. 「アプリ」 > 「インストールされているアプリ」へ進む。
4. 検索ボックスで「Teams」と検索し、「Microsoft Teams」を見つける。
5. 右側の「…（3つの点）」をクリックし、「詳細オプション」を選択。
6. 画面を下へスクロールし、「リセット」セクションの「リセット」ボタンをクリック（確認ポップアップも「リセット」を選択）。
7. チェックマークが表示されたらTeamsを再起動し、履歴が読み込まれるか確認する。

#### パターンB：従来のTeams（Classic Teams）の場合

ユーザープロファイル配下のローカルキャッシュを手動で削除する。

1. システムトレイのTeamsアイコンを右クリックし、「終了」を選択。
2. `Windows + R` キーを押して「ファイル名を指定して実行」を開く。
3. `%appdata%\Microsoft\Teams` と入力してEnterを押す。
   （※存在しない場合は `%localappdata%\Microsoft\Teams` を確認）
4. 開いたフォルダ内のファイルとフォルダを **すべて削除** する。
5. Teamsを再起動し、履歴が読み込まれるか確認する。
